
# Project Roll

Project Roll é um jogo de plataforma 3D desenvolvido na Unity, no qual o jogador controla uma esfera e precisa superar desafios de parkour para alcançar o final de cada fase.

## Sobre o jogo

O jogo possui uma perspectiva 3D e utiliza física para controlar a movimentação da esfera. Ao longo das fases, o jogador encontrará plataformas, obstáculos e desafios com dificuldade progressiva.

## Tecnologias utilizadas

- Unity 6
- C#
- Universal Render Pipeline (URP)
- Git e GitHub

## Controles

| Tecla | Ação |
|---|---|
| W / ↑ | Mover para frente |
| S / ↓ | Mover para trás |
| A / ← | Mover para esquerda |
| D / → | Mover para direita |
| Espaço | Pular |
| R | Reiniciar no último checkpoint |

## Funcionalidades

- Movimentação física da esfera.
- Sistema de pulo.
- Câmera que acompanha o jogador.
- Detecção de queda e respawn.
- Sistema de checkpoints.
- Menu inicial com opção de iniciar o jogo.
